## Item delivered in M7c.6

New `cassini-client` module (`io.vidocq.cassini:cassini-client:0.1.0-SNAPSHOT`) —
zero-dep `jakarta.ws.rs.client.ClientBuilder` impl based on `java.net.http.HttpClient`
+ virtual threads. Discovered via ServiceLoader (`META-INF/services`) and JPMS `provides`.

Scope of commit #2:
- `ClientBuilder`, `Client`, `WebTarget`, `Invocation.Builder`, `Invocation`
- All synchronous HTTP methods (GET/POST/PUT/DELETE/HEAD/OPTIONS/TRACE/method)
- URI templating via `CassiniUriBuilder` (reused from cassini-core)
- Headers, accept, queryParam, resolveTemplate
- Response via `CassiniClientResponse` (UTF-8 decode + Content-Type charset)
- `CassiniClientRuntimeDelegate` (local subclass of `CassiniRuntimeDelegate` —
  JPMS constraint forbids `provides X with Y` if Y is in another module)

Out of scope for M7c.6 (pushed to M2d.2 in the cassini ROADMAP):
- Async via `InvocationCallback` / `CompletionStageRxInvoker`
- Request body serialization via `MessageBodyRegistry` (POJO JSON-B…) — commit #3 if needed
- CLIENT filters (`ClientRequestFilter`/`ClientResponseFilter`) — commit #4 / required for M7c.7

Related changes in cassini:
- reactor `pom.xml`: `<subproject>cassini-client</subproject>` + DM entry
- `cassini-core/module-info.java`: `exports internal{,.runtime} to io.vidocq.cassini.client`
- `cassini/ROADMAP.md`: correction to M2d (milestone was marked `✅` by mistake — had never been implemented)

Unit tests: **6/6 PASS** (ClientBuilderDiscoveryTest + BasicGetTest with ephemeral in-process FakeHttpServer
`com.sun.net.httpserver.HttpServer`).

## Why the net PASS is unchanged

Tests using `ClientBuilder.newClient()` (`BaggageTest`, `RestClientSpan*Test`,
`RestSpan*Test`) used to crash BEFORE in `setUp` with `ClassNotFoundException`. With cassini-client:
- ✅ `setUp` reaches the runtime (`ClassNotFoundException` disappears)
- ❌ Tests now fail on orthogonal blockers:
  - CLIENT spans not instrumented around JAX-RS Client requests → **M7c.7** (`humboldt-rest`
    `ClientRequestFilter` + `ClientResponseFilter` that create a `kind=CLIENT` span with
    OTel HTTP semantic convention attrs)
  - `testIntegrationWithJaxRsClient`, `testIntegrationWithJaxRsClientAsync`,
    `testIntegrationWithJaxRsClientError`: need M7c.7
  - `testIntegrationWithMpRestClient*`: need M7c.12 (cyrano MP Rest Client filters)
  - `baggage()`: HTTP 500 on the server side — investigation required (SpanResource likely
    makes an outgoing call or a baggage access that crashes)
  - `b3*Propagation`, `jaegerPropagation`: optional non-W3C propagators — cluster D

## Cassini non-regression validation
