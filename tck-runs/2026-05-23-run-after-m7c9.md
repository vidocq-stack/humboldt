## Item delivered in M7c.9

Patch **`cassini-core/Invoker.java`** — 2 modifications in `invokeInternal()` right
before the post-matching filters loop (~5 total lines):

1. Set `CURRENT_MATCH.set(match)` + `CURRENT_REQUEST.set(request)` so that
   `injectProviderContexts()` can populate the providers' `@Context` fields
2. Call `injectProviderContexts(fe.instance(), request)` before each
   `fe.instance().filter(rctx)` in the loop

Behavior: singleton filters' `@Context ResourceInfo`, `@Context UriInfo`, etc.
fields are now populated on each request (JAX-RS spec §9.2 style — already done
for MessageBodyReader/Writer previously).

**Known limitation**: not thread-safe for intensive concurrent use (singleton
fields are overwritten on each request, possible race between threads). Acceptable
for the TCK + normal usage. For concurrent safety, a per-thread proxy would be needed
(M7c.10 or later).
