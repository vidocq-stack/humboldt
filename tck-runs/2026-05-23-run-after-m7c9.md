## Item livré en M7c.9

Patch **`cassini-core/Invoker.java`** — 2 modifications dans `invokeInternal()` juste
avant la boucle post-matching filters (~5 lignes au total) :

1. Set `CURRENT_MATCH.set(match)` + `CURRENT_REQUEST.set(request)` pour que
   `injectProviderContexts()` puisse alimenter les `@Context` fields des providers
2. Appel `injectProviderContexts(fe.instance(), request)` avant chaque
   `fe.instance().filter(rctx)` dans la boucle

Comportement : les fields `@Context ResourceInfo`, `@Context UriInfo`, etc. des
filters singletons sont désormais alimentés à chaque request (style §9.2 de la spec
JAX-RS — déjà fait pour MessageBodyReader/Writer auparavant).

**Limitation connue** : non thread-safe pour usage concurrent intensif (les fields
singletons sont écrasés à chaque request, race possible entre threads). Acceptable
pour TCK + cas d'usage normal. Pour concurrent-safe, il faudrait un proxy par-thread
(M7c.10 ou ultérieur).
