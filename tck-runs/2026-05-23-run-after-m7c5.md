## Remaining blockers to finish M7c.5 globally

### Blocker 1: missing JAX-RS Client impl (= M7c.6)

`jakarta.ws.rs.client.ClientBuilder` has no provider in the humboldt-tck
classpath (API only). Cyrano implements MP Rest Client 4.0 (the
`RestClientBuilder` interface), not JAX-RS Client 4.0 (the `ClientBuilder` interface).

Solutions:
- A) Implement a minimal `cassini-client` (using chappe-client + JDK
  HttpClient as backend) → ~600-800 LOC
- B) Add Jersey in test-scope → potential conflict with Cassini server +
  non-zero-dep ecosystem
- C) Document these tests as out-of-scope (Vidocq adopts MP Rest Client as the
  reference client, not direct JAX-RS Client)

### Blocker 2: Arquillian lifecycle shared between tests

In the full suite (vs isolation), the `RestClientSpanTest` tests (without Default) all have
`setUp` failing → tests skipped. Likely the Arquillian state (container,
GlobalOpenTelemetry, cyrano deps) is not cleanly reset between tests.

Reproduction:
- In suite: 0 PASS on RestClientSpan*Test
- In isolation: 3 PASS on RestClientSpanDefaultTest

To investigate in a dedicated item (M7c.13).

### Blocker 3: HTTP 500 on the server side

`SpanResource` (the test endpoint) likely makes an outgoing call via
`ClientBuilder.newClient()` that crashes. Related to blocker 1.
