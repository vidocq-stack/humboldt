## Blocker identified → M7c.9

`HumboldtDeployableContainer.deploy()` instantiates the filter via `new` and passes it to
`CassiniHarness.Builder.provider(Object)`. This API does not invoke JAX-RS
`@Context` injection → `ResourceInfo` stays null in the filter.

Possible solutions:
- Extend `CassiniHarness.Builder` with `providerClass(Class<?>)`, which instantiates through
  Cassini and performs JAX-RS injection (`@Context UriInfo`, `@Context ResourceInfo`, etc.)
- Or implement a "post-routing property injection" mechanism: Cassini stores the matched
  `ResourceMethod` in a `ContainerRequestContext` property before
  calling post-matching filters, and the filter retrieves it via `getProperty()`

Estimated impact: tests that assert templated `HTTP_ROUTE` (RestSpanTest.spanName,
RestSpanDefaultTest, RestSpanDisabledTest, possibly JaxRsClient*Test) — ~5-8 tests.
