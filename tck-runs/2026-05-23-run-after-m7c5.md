## Bloqueurs restants pour finir M7c.5 globalement

### Bloqueur 1 : JAX-RS Client impl manquant (= M7c.6)

`jakarta.ws.rs.client.ClientBuilder` n'a pas de provider dans le classpath
humboldt-tck (uniquement l'API). Cyrano implémente MP Rest Client 4.0 (interface
`RestClientBuilder`), pas JAX-RS Client 4.0 (interface `ClientBuilder`).

Solutions :
- A) Implémenter un `cassini-client` minimal (utilisant chappe-client + JDK
  HttpClient en backend) → ~600-800 LOC
- B) Ajouter Jersey en test-scope → conflit potentiel avec Cassini server +
  écosystème non zéro-dep
- C) Documenter ces tests comme hors-scope (Vidocq adopte MP Rest Client comme
  client de référence, pas JAX-RS Client direct)

### Bloqueur 2 : Lifecycle Arquillian partagé entre tests

En suite globale (vs isolation), les `RestClientSpanTest` (sans Default) ont tous
leurs `setUp` qui fail → tests skip. Probable que l'état Arquillian (container,
GlobalOpenTelemetry, deps cyrano) n'est pas reset proprement entre tests.

Reproduction :
- En suite : 0 PASS sur RestClientSpan*Test
- En isolation : 3 PASS sur RestClientSpanDefaultTest

À investiguer dans un item dédié (M7c.13).

### Bloqueur 3 : HTTP 500 côté serveur

`SpanResource` (endpoint des tests) probablement fait un appel sortant via
`ClientBuilder.newClient()` qui crash. Lié au bloqueur 1.
